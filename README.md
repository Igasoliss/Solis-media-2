# Solís Media

Landing page de Solís Media para WordPress, más material para redes sociales.

## Contenido
- `wordpress/bloques-wordpress.html`: bloques de Gutenberg. Se pegan en el editor de código de una página.
- `wordpress/estilos-solis-media.css`: va en Apariencia > Personalizar > CSS adicional.
- `wordpress/foto-ignacio.jpg`: foto de la sección "Quién te atiende". Subir a la biblioteca de medios y usar "Reemplazar".
- `wordpress/vista-previa.html`: vista previa aproximada; ábrela en el navegador.
- `redes/posts`: 10 posts de Instagram (1080x1350).
- `redes/logos`: 8 versiones del logo (1080x1080).
- `generador`: scripts de Python que generan los bloques y los posts.

## Antes de publicar
Cambiar los datos de ejemplo: WhatsApp (`56900000000`), correo (`hola@tudominio.cl`), Instagram (`tu_usuario`) y el formulario de contacto.

## Marca
Colores: #FFFFFF, #1A1217, #E4F062. Tipografía: Poppins.
